%\part{Conclusion and Future Work}
Through this work, we conclude the advantages that ROS 2 brings to the industrial environment and the potential offered by OpenRMF. In this chapter, we describe all the advantages we have discovered.
\chapter{Conclusion}
With this work, we demonstrate the potential of ROS 2 for creating industrial robotics solutions.\\
From porting the code, we discovered the Lifecycle and Compose options for creating nodes.
The new Lifecycle state machine available for nodes allows for better management of interactions between nodes. It allows for control in the event that a node crashes or fails to change state, affecting the behavior of other nodes.
The Composite feature allows for optimized data transmission.\\
Furthermore, for creating AMRs, the modularity and large number of solutions for each problem allow for easy modifications to plugins and nodes, facilitating rapid implementation. The configurability of nodes enables these performance improvements with minimal code changes.
Nav2's modularity allowed for quick import of code from our planner, allowing us to evaluate its advantages and disadvantages.\\
Finally, OpenRMF demonstrates its potential. Thanks to its tools, it allows the rapid creation of complex navigation graph paths, it also allows brand-independent robot infrastructures, allows the easy import of different robots with an dedicated package for ROS robots, allows the control of structural elements such as doors and lifts and allow to perform different task without conflicts with other robots.\\
In the office environment we see advantages of the AMR with openrmf, since the robots are able to move avoiding collision with persons.
\chapter{Future work}
Using OpenRMF, we can create nodes that, thanks to an extensive language model, can send tasks to the robot. We aim to implement this functionality in our warehouse, allowing us to effectively control the robot. Additionally, with the Fleet Adapter, which forms the basis of the Free Fleet package, we can manage other robots in our fleet. We've also identified ways to improve the planner.

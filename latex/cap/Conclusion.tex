\part{Conclusion and Future Work}
Over this work we conclude the advantages ROS 2 brings for the industrial environment and the potentiality that OpenRMF brings. In this chapter we describe all the advantages we discovered.
\chapter{Conclusion}
The new LifeCycle state machine available for the nodes allow to better manage the interaction between the nodes, allowing to control in the event that some node crash or some node to fail to change state the behavior of other nodes, like if the node that control some sensor fail to output and change state or crashed can stop the Nav2 nodes and make the robot go to a safe state. 
Also for building AMR the modularity and the big number of solution for each problem allow to change plugins and node easily allowing to allow a fast deploy.
The configurability of the nodes allow to find the best performance with little change of code.
The configurability of the new launch system for the nodes allow to control the sequence and avoid to launch nodes if some failed to execute.
The modularity of Nav2 allowed the fast import of the code from our planner and to see his advantages and the disadvantages.
The Dstar algorithm show the advantages to have the path saved and to be loaded at needed.
The OpenRMF show the possiblies that can be implemented.

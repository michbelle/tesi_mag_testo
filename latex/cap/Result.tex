\chapter{Presentation of results from testing and evaluation}
This part is divided based on the things that have been completed:
\begin{itemize}
	\item porting the planner DStarGlobalPlanner from ROS 1 to ROS 2.
	\item "building" two Autonomous Mobile Robots (AMR):
	\begin{itemize}
		\item from scratch and using the Rover Robotics Mini platform.
		\item proving the portability of the code structure used for the Jobot updating it to ROS 2.
	\end{itemize}
	\item implement the Open-RMF middleware using these robots.
\end{itemize}

\subsection{In particular for the Mini}
We found issues with position estimation, which we resolved by tuning the parameters of the AMCL accordingly. We achieved the best performance with the following values for the process covariance matrix: 
$v_{yaw}$ of 10.0
and for AMCL: $\alpha 1$ 0.01, $\alpha 2$ 0.01, $\alpha 3$ 0.1 and $\alpha 4$ 0.0001
\section{In particolar for the jobot}
We converted all the code used to control the robot from ROS 1 to ROS 2, demonstrating the portability of that code structure. We added the Lifecycle to be implemented as part of the boot sequence of the robot with Nav2 and its sensors. 
We corrected the estimation in rotation by combining the velocity estimates from the robot and the gyroscope and with the AMCL we corrected the remaining error.
$v_{yaw}$ of 320.0
and for AMCL: $\alpha 1$ 0.01, $\alpha 2$ 0.001, $\alpha 3$ 0.001 and $\alpha 4$ 0.001

\section{Planner calculation time comparison}
In this section, we show the time required for the global planner node to calculate different path, we comparated the performance between the DStar global planner and the NavfnPlanner over 3 path: from the office to the storage room (used as base in the setting up the parameters), from the office to the entrance of the building (fig: \ref{Dstar:uff->entr},\ref{Navfn:uff->entr})and from the entrance to the our CAD designers location(fig:\ref{Dstar:entr->CAD},\ref{Navfn:entr->CAD}). The results were obtained in a jazzy docker image with a Intel i5-1345U CPU and adding the flag: \\ \hspace*{1cm}\texttt{--cmake-args -DCMAKE\_BUILD\_TYPE=Release}\\ to the call of \texttt{colcon build}.
